# 🌿 Plataforma Íris - Design System

Bem-vindo ao Design System da **Plataforma Íris**. Este espaço foi criado para documentar e visualizar os componentes que compõem nossa plataforma de saúde mental, garantindo consistência, empatia e uma experiência premium.

## 🎨 Princípios de Design

1.  **Empatia**: Cores suaves e interações gentis.
2.  **Segurança**: Feedbacks visuais claros sobre criptografia e privacidade.
3.  **Clareza**: Tipografia legível e espaços generosos.
4.  **Premium**: Uso de glassmorphism e micro-animações.

## 🛠️ Como usar este Storybook

Navegue pelo menu lateral para explorar os componentes:
- **Shared**: Componentes básicos como Botões e Cartões.
- **Features**: (Em breve) Componentes específicos de funcionalidades.
